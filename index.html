📖 Log Format Guide

Instant parsing rules and field definitions across major log sources:

🪟 Windows EVTX: EventID, LogonType, SubStatus (0xC000006A wrong pwd, 0xC0000064 no user), ElevatedToken.
🌐 IIS W3C Web: s-ip (Server), c-ip (Client), cs-method, cs-uri-query, sc-status, sc-bytes.
🐧 Linux Syslog (RFC 5424): Severities 0-7 (0=emerg, 1=alert, 2=crit, 3=err), PRI = (Facility * 8) + Severity.
🛡️ Snort IDS: alert proto src -> dst (msg; content; sid; rev;) with classification and priority.
